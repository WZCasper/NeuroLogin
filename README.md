# NeuroLogin

Telegram-бот для пошагового опроса пользователей с ветвлением логики,
человеческим подтверждением ответов перед сохранением и веб-панелью
администратора. Работает полностью бесплатно: бот — на GitHub Actions,
панель — на GitHub Pages, хранилище — JSON-файлы в этом репозитории
(плюс копия каждой анкеты дублируется в служебную Telegram-группу).

## Структура

- `bot/` — Telegram-бот (TypeScript, Telegraf)
- `docs/` — статическая админ-панель (GitHub Pages)
- `data/` — данные: `users.json`, `sessions.json`, `survey.json`, `media/`
- `.github/workflows/bot.yml` — запуск бота через GitHub Actions

## Настройка бота

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен.
2. (Опционально) Создайте служебную группу, добавьте в неё бота,
   узнайте её `chat_id` (например, через @getidsbot или через `getUpdates`).
3. Создайте GitHub Personal Access Token (fine-grained, только для этого
   репозитория, права `Contents: Read and write`) — он нужен, чтобы бот
   мог коммитить `data/*.json` обратно в репозиторий.
4. В репозитории: **Settings → Secrets and variables → Actions** добавьте:
   - `BOT_TOKEN` — токен бота
   - `ADMIN_GROUP_ID` — id служебной группы (можно пропустить)
   - `GH_TOKEN` — Personal Access Token из шага 3
5. Запустите workflow вручную (**Actions → Run NeuroLogin Bot → Run workflow**)
   или дождитесь автоматического запуска по расписанию.

## Настройка админ-панели

1. **Settings → Pages → Source**: выберите ветку `main`, папку `/docs`.
2. Откройте опубликованный адрес (обычно
   `https://wzcasper.github.io/NeuroLogin/`).
3. Нажмите «Ввести токен» и вставьте свой personal access token с правами
   `Contents: Read and write` на этот репозиторий — он нужен только для
   сохранения правок (редактирование анкет, конструктор опроса) и хранится
   исключительно в текущей вкладке браузера (`sessionStorage`), никуда,
   кроме `api.github.com`, не отправляется.

## Как редактировать вопросы и ветвления

Вкладка «Опрос и ветвления» в панели позволяет менять текст вопросов,
тип ответа (текст/фото/файл), следующий шаг по умолчанию и ветвления вида
`ответ1=шаг1, ответ2=шаг2`. После сохранения бот на следующем сообщении
пользователю подхватит новую версию `data/survey.json` автоматически —
перезапускать бота не нужно.

## Локальный запуск бота (для отладки)

```bash
cd bot
npm install
cp .env.example .env   # заполните BOT_TOKEN
npm run build
npm start
```

## Важно про безопасность токенов

Никогда не публикуйте `BOT_TOKEN` или GitHub PAT в чатах, issue или коде.
Храните их только в Actions Secrets (для бота) и вводите GitHub-токен в
админ-панели только на своём устройстве.
