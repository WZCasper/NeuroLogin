# NeuroLogin

Telegram-бот для пошагового опроса пользователей с ветвлением логики и
человеческим подтверждением ответов перед сохранением. Бота можно добавить
в любое количество групп — в каждую его добавляет администратор этой
группы, и данные каждой группы хранятся отдельно.

Работает полностью бесплатно: бот — на GitHub Actions, панель
администратора — на GitHub Pages, хранилище — JSON-файлы в этом
репозитории. Каждая подтверждённая анкета дополнительно дублируется
сообщением прямо в ту группу, из которой пришёл пользователь.

## Как это работает

1. Администратор группы добавляет бота в свою группу.
   - Бот проверяет, что добавивший — админ. Если нет, бот сразу выходит
     из группы.
   - Группа регистрируется в `data/groups.json`.
2. Когда в группу заходит новый участник, бот присылает в группу кнопку
   «Пройти опрос» — она открывает личный чат с ботом.
   Также можно запустить это вручную: `/start` прямо в группе.
3. В личном чате бот задаёт вопросы по очереди, поддерживает ветвление
   (например, разные вопросы для ПК и консоли) и приём фото.
4. В конце — экран подтверждения («Подтвердить» / «Изменить»).
5. После подтверждения данные сохраняются в
   `data/groups/<chat_id>/users.json`, коммитятся в репозиторий, и копия
   уходит сообщением обратно в группу.

## Структура

- `bot/` — Telegram-бот (TypeScript, Telegraf)
- `docs/` — статическая админ-панель (GitHub Pages), с выбором группы
- `data/groups.json` — реестр групп, куда добавлен бот
- `data/groups/<chat_id>/users.json` — анкеты участников этой группы
- `data/groups/<chat_id>/survey.json` — свой опрос для этой группы (необязательно)
- `data/groups/<chat_id>/media/` — фото, приложенные участниками этой группы
- `data/survey.json` — опрос по умолчанию для групп без своей настройки
- `.github/workflows/bot.yml` — запуск бота через GitHub Actions

## Настройка бота

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен.
2. Создайте GitHub Personal Access Token (fine-grained, только для этого
   репозитория), права: **Contents — Read and write**,
   **Workflows — Read and write**.
3. В репозитории: **Settings → Secrets and variables → Actions** добавьте:
   - `BOT_TOKEN` — токен бота
   - `GH_TOKEN` — токен из шага 2
4. **Settings → Pages**: Source = Deploy from a branch, ветка `main`,
   папка `/docs`.
5. **Actions → Run NeuroLogin Bot → Run workflow** — первый запуск вручную.

## Как добавить бота в свою группу

1. Добавьте бота как участника вашей группы (это должен сделать
   администратор группы — иначе бот сам выйдет).
2. Дайте боту право отправлять сообщения (по умолчанию этого достаточно,
   права администратора группы боту не нужны).
3. Готово — бот будет приветствовать новых участников и предлагать пройти
   опрос.

## Как редактировать вопросы и ветвления

Откройте админ-панель, выберите группу в выпадающем списке вверху,
перейдите на вкладку «Опрос и ветвления». Можно менять текст вопросов,
тип ответа (текст/фото), шаг по умолчанию и ветвления вида
`ответ1=шаг1, ответ2=шаг2`. Сохранение создаёт отдельный опрос именно
для выбранной группы — на другие группы это не влияет.

## Локальный запуск бота (для отладки)

```bash
cd bot
npm install
cp .env.example .env   # заполните BOT_TOKEN
npm run build
npm start
```

## Важно про безопасность токенов

Никогда не публикуйте `BOT_TOKEN` или GitHub PAT в чатах, issue или коде.
Храните их только в Actions Secrets (для бота) и вводите GitHub-токен в
админ-панели только на своём устройстве — он остаётся в этой вкладке
браузера и нигде больше не сохраняется.
