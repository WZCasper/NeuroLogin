Вход по GitHub-токену

Для владельца репозитория. Токен с правом Contents: Read and write сразу даёт доступ ко всем группам и позволяет сохранять изменения — без Telegram и без ожидания.

Токен для сохранения изменений

Вход через Telegram нужен, чтобы показать ваши группы и участников. А чтобы что-то изменить (правки анкет, конструктор опроса), дополнительно нужен GitHub-токен с правом записи. Он хранится только в этой вкладке браузера.
